# Niky Chemical Product (NCP)

Plateforme web e-commerce et académie de formations pratiques pour **Niky Chemical Product (NCP)** en Haïti.

## Technologies
- **Framework**: Next.js 14 (App Router)
- **Langage**: TypeScript
- **Styling**: Tailwind CSS & Lucide Icons
- **Base de données**: Supabase
- **Paiements**: Digicel MonCash (REST API) & Paiement à la livraison (HTG)
- **Gestion d'état**: Zustand

## Lancer le projet en local
```bash
cd web
npm install
npm run dev
```
Ouvrez [http://localhost:3000](http://localhost:3000).
